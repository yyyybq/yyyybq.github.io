      01 / Design

      A home where time, state, and action all matter

      ELE places an embodied agent in a fully furnished, fully interactive apartment. The world keeps running while the agent thinks, objects carry physical state that evolves on its own, and every task is a long-horizon household job executed end to end.

      A

      One interactive home

      Home1 is a complete apartment: kitchen, living room, study, bathroom and balcony. Doors, drawers, appliances, lights, curtains and furniture are articulated and operable.

      See close-up interactions →
      B

      World time never pauses

      Reasoning is not free. A world clock keeps advancing while the model plans, so slow deliberation costs real in-scene time. A single tidy-up can take hours of wall-clock time.

      Watch rollouts with reasoning →
      C

      Actions have consequences

      States evolve whether or not the agent attends to them. Leave the stove on too long and the egg burns; forget the tap and the sink overflows.

      See temporal consequences →
      D

      Long-horizon, decomposable tasks

      Household jobs such as making coffee, putting away groceries, or cooking breakfast chain many sub-steps, each with a checkable intermediate state.

      Browse stage breakdowns →

      02 / Temporal Consequences

      The world does not wait for the agent

      Physical processes keep running in the background. Acting late is a failure with a visible outcome, not just a lower score.
